# Startup Workflow

Use this at the start of a Codex or OpenCode session.

1. Confirm the working directory is `my-classroom-tools`.
2. Read `AGENTS.md`.
3. Check `git status --short`.
4. Read the Obsidian work note:
   `Projects/my-classroom-tools/工作筆記.md`
5. Run `git fetch origin` if there are no local changes.
6. Report current state, risks, and the suggested next step.

Do not run `git pull` automatically when local changes exist.
