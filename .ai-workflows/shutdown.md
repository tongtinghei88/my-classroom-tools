# Shutdown Workflow

Use this before ending a Codex or OpenCode session.

1. Review changed files.
2. Update the Obsidian work note:
   `Projects/my-classroom-tools/工作筆記.md`
3. Stage only relevant files.
4. Commit with a clear message.
5. Push to GitHub.
6. Report:
   - GDrive path
   - Obsidian note updated
   - Git commit hash
   - GitHub repo URL

Never stage `.claude/`, `.codex/`, `.opencode/`, `.env`, credentials, or tokens.
